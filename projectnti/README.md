💳 Loan Repayment Prediction

📌 About the Project

This project aims to predict whether a person will repay a loan or not based on different customer and financial features.

---

🔍 What I Did

- 🧹 Data Cleaning & Preprocessing
- 📊 Exploratory Data Analysis (EDA)
- 📈 Data Visualization
- ⚙️ Feature Engineering
- 🎯 Feature Selection
- 🤖 Training Multiple Machine Learning Models
- 📏 Model Evaluation
- 🏆 Selecting the Best Model

---

🤖 Machine Learning Models

The following models were trained and compared:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Boosting
- Artificial Neural Network (ANN)

---

🏆 Best Model

🌲 Random Forest

After comparing the different models, Random Forest achieved the best performance on the project dataset.
